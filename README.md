# Creator Studio & Developer Portfolio 🚀

Portafolio y estudio de creador inspirado en el diseño minimalista y moderno de [elifcodesstudio.com](https://www.elifcodesstudio.com/en), construido con **React 19 + TypeScript + Tailwind CSS v4 + Vite**.

## ✨ Características y Secciones

- ⚡ **Ticker Marquee Superior**: Cinta de anuncios interactiva con animación infinita.
- 💎 **Barra de Navegación Sticky**: Con selector de idioma (**ES / EN**), logotipo con asterisco distintivo y menú responsivo.
- 🌌 **Hero Section**: Fondo oscuro ambiental con badges tipográficos monospace, tipografía display elegante y botón de llamada a la acción.
- 🛠️ **Creaciones y Productos Destacados**:
  - **Motif Showcase**: Mockup de interfaz de dashboard con estadísticas, estado de proyectos y cuadrícula de 8 características con iconos.
  - **Setuply (Mobile App)**: Badge de rating, viñetas de características, botón para App Store y mockups angulados con gradiente de máscara.
  - **Commitchi (Dev Tool)**: Ventana de terminal simulada, contador interactivo de rachas (`streak`) y mascota pixelada animada.
- 💌 **Newsletter ("Enterate primero")**: Formulario de suscripción estilizado con fondo punteado radial.
- 🌐 **Ecosistema del Estudio**: Tarjetas con gradientes atmosféricos y efecto zoom al pasar el mouse.
- 🖥️ **Mi Setup (My Desk)**: Especificaciones de hardware y herramientas de trabajo.
- 📬 **Reach Me (Contacto)**: Accesos directos a Email, Instagram, GitHub y X (Twitter).
- ⚙️ **100% Personalizable**: Todos los textos, enlaces, productos y datos se editan fácilmente en [`src/data/portfolioData.ts`](./src/data/portfolioData.ts).

## 🚀 Cómo Ejecutar el Proyecto

1. Abrir la terminal en la carpeta del proyecto:
   ```bash
   cd portfolio-react
   ```

2. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```

3. Abrir en tu navegador el enlace que muestre la consola (usualmente `http://localhost:5173`).

## 🛠️ Comandos Disponibles

- `npm run dev`: Inicia el servidor de desarrollo local.
- `npm run build`: Compila el proyecto para producción con TypeScript.
- `npm run preview`: Previsualiza la versión de producción localmente.
